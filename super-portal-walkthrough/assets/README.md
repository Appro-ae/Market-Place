# Brand assets

Drop the Appro logo files here.

| File | Ground | Used for |
|---|---|---|
| `logo-white.svg` (or `.png`) | dark navy | Portal sidebar — 31 shots — and the title card |
| `logo-dark.svg` (or `.png`) | white | Pre-approval letterhead, shot 28 |

Native ratio is **3.45 : 1**. Scale by width only; height always follows.
No recolouring, opacity, shadow, glow, outline or container box. Never redraw —
these files only.

The white version looks blank when previewed on a white background. That is
correct; it is white artwork on transparency.

## Note on the sidebar

`logo-white` must be loaded into the demo tenant's channel branding **before**
screenshots are captured. It is baked into all 31 sidebar shots at capture time
and cannot be composited in afterwards.
