05

Open decisions before backend build

The live blocker list. Owner: Gấu trắng, decision authority: Huyen. Cleared items get struck through on update.
  1. Manual "Buyout details" screen vs AECB auto-fill — kill the manual screen (recommended). Conflict, screen ref §06-1
  2. Processing-fee card payment vs deduct-from-finance — no PSP in B2B (recommended). Conflict, §06-2
  3. One signature model per document class (swipe / drawn / EFR+OTP) before AMP-3757.
  4. Hard-gate defaults: BP (G2≥2, G3≥30%) vs DP DC engine (G2≥3, G3≥70%) — deliberate or drift?
  5. Extend G4 standing check to Buyout (market requires good standing; spec gates DC only).
  6. Settlement-execution workflow (manager's cheque, status, reconciliation) — needs a new US.
  7. Cooling-off AC12 behaviours (applied / ends / waived) are empty in the ticket.
  8. Shortfall check trigger point: AMP-3732 AC6 (pre-submission) vs AMP-3404 AC6a (post-offer).
  9. Liability-letter validity default = 15 days; grace-period ceiling configurable (FAB competes at 365).
  10. 48-month CBUAE tenor cap — add platform validation, not only Product Setup config.
