2 · The week, day by day

Day 1 Setup and validation AC1 AC8 AC10

  • Admin adds Alice with Staff ID STF-042 and Reporting Manager Jane Smith. A Maker request is created; the Checker sees Staff ID: — → STF-042 · Reporting Manager: None → Jane Smith and approves. Alice's Staff ID is now read-only.
  • Admin adds Omar with Staff ID stf-042. IEM001 — Staff ID already exists Match is case-insensitive and trimmed, so the save is blocked before any Maker request is created.
  • Admin tries to set Fatima's Reporting Manager to Alice. IEM002 — This assignment would create a circular reporting chain Fatima → Alice → Jane → Fatima would loop.

Jane, John, Fatima and Sara see the Assigned To (Sale Staff) column by default; Alice does not — her list only ever holds her own rows (AC9). Sara sees "—" for A2 and A5. Report Enquiry follows the same scope: Fatima's report covers A1, A3, A4; Alice's covers A1; Sara's covers all five.

Day 3 Alice moves to John's team AC8 AC10

Admin changes Alice's Reporting Manager from Jane to John. Checker sees Reporting Manager: Jane Smith → John Doe and approves. Immediately: John's list gains A1, Jane's list loses A1, Fatima's is unchanged. A1's tag is still Alice — attribution never moves; visibility follows the current hierarchy. Toggle "After Day 3" in Section 3 to see it.

Day 5 Jane resigns AC8

Jane has no direct reports any more (Alice moved), so IEM003 does not fire. But she still owns A3, which is In Progress.

IEM004 — This user has 1 open tagged application(s). Reassign their cases before deactivating.

Deactivation stays blocked until A3 is reassigned or reaches a terminal status — this is the step where the story still needs the reassignment function (known open point).

Day 6 Sara works the alerts AC4 AC7

From the two ET51 emails Sara opens A2 and A5 — she can, via View All. A2's code was a typo for Alice; A5 needs the Personal Loan pool to be configured. Until then both stay visible only to View-All users.

Go-live weeks earlier IA2

None of the historical applications carried a tag. Every existing enquiry user — Alice included — was granted View All Applications, so nobody's screen went empty. Once Alice's incoming cases were flowing in tagged, the admin removed View All from the Sales Officer role and her list narrowed to her own cases.
