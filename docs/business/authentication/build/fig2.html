Signing in with a portal password
1
Enter email and password
Select Login. The password can be shown or hidden.
2
The portal checks the account
Account type and status first, then the password.
3
One-time code by email
6 digits, valid for 10 minutes. Resend OTP appears after a 60-second countdown.
4
Verify and Login
The correct code opens the landing screen.
5
Session
Signed out after 5 minutes of inactivity, with a 30-second warning.
When the attempt does not go through
Wrong password or unknown emailSame message in both cases — the page never reveals whether an email exists.
5 failed attempts within an hourThe account is locked. Fewer failures clear the next hour.
Password expired or lockedTold to reset the password through “Forgot password?”.
Account signs in with single sign-onTold to select “Login with SSO” — or that single sign-on is off.
Wrong or expired codeAsked to try again. Resend issues a new code and cancels the old one.
More than 5 wrong codes in a dayVerify and Resend are disabled for 1 hour, with a countdown.
Account inactiveTold the account is inactive and to contact the administrator.
Invitation not yet usedTold no password has been set, and to check the invitation email.
