How a version moves

  1. Download the product's .drawio master from its card (or take it from the repo under docs/workflow/).
  2. Edit in draw.io (app.diagrams.net or desktop) — or describe the change to the agent, which edits the master directly.
  3. Send the file back (the .drawio itself, or a draw.io PDF export — the PDF carries the diagram source). The repo, the renders, this page and the registry are updated and the version is bumped.
